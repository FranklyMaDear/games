📍 Τοποθεσία
Για κοινή θέση στον χάρτη
📍 Πώς ενεργοποιείς την τοποθεσία

iPhone / iOS (Safari):

  1. Άνοιξε την εφαρμογή Ρυθμίσεις
  2. Κάτω → Safari → Τοποθεσία → επίλεξε Ερώτηση ή Επιτρέπεται
  3. Ή: Safari → aA (αριστερά στη γραμμή διεύθυνσης) → Ρυθμίσεις ιστότοπου → Τοποθεσία → Επιτρέπεται
  4. Επίσης: Ρυθμίσεις → Απόρρητο & Ασφάλεια → Υπηρεσίες τοποθεσίας → ενεργό, και Safari → Ενώ χρησιμοποιείται

Android (Chrome):

  1. Πάτα το εικονίδιο κλειδαριάς ή ℹ️ δίπλα στη διεύθυνση
  2. Άδειες / Permissions → Τοποθεσία → Επιτρέπεται
  3. Ή: Ρυθμίσεις τηλεφώνου → Εφαρμογές → Chrome → Άδειες → Τοποθεσία → Επιτρέπεται

Αν άνοιξες τον σύνδεσμο μέσα από Messenger / Viber / Instagram, πάτα «Άνοιγμα στο Chrome / Safari» πρώτα.
